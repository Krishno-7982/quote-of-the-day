# ✨ Quote of the Day

A simple and interactive **Quote of the Day** website developed as a mini project assigned by our Faculty Advisor (FA). The website displays an inspirational quote to motivate users and brighten their day.

## 📌 About the Project

Quote of the Day is a lightweight web application built using HTML, CSS, and JavaScript. It provides users with daily inspiration through motivational quotes in a clean and attractive interface.

Users can click the **"New Random Quote"** button to generate another random quote without refreshing the webpage.

## 🚀 Features

- **Random Quotes:** Displays inspirational and motivational quotes.
- **New Random Quote:** Get a different quote with a single click.
- **Date Display:** Shows the current date on the webpage.
- **Simple User Interface:** Clean, attractive, and user-friendly design.
- **Responsive Layout:** Designed to provide a pleasant viewing experience.

## 🛠️ Technologies Used

- **HTML5** – Used to create the structure of the webpage.
- **CSS3** – Used for styling, layout, colors, and visual appearance.
- **JavaScript** – Used to implement the random quote functionality and user interactions.

## 💻 How to Run the Project

Follow these steps to run the project on your local machine:

1. Clone the repository:

   
   git clone <>
   

2. Navigate to the project directory:

  
   cd quote-of-the-day
  

3. Open the `index.html` file in your preferred web browser.

4. Click the **"New Random Quote"** button to explore different inspirational quotes.

No additional installations or dependencies are required.
